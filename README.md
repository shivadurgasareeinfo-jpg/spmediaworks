## GitHub Pages

1. Create a public GitHub repository.
2. Upload the files while preserving the folder structure.
3. Enable GitHub Pages from Settings → Pages.
4. Set the custom domain to `spmediaworks.linkpc.net`.
5. In DNSExit, configure the required CNAME for the subdomain according to GitHub's current Pages instructions.
